 # Meri pehli website-Web Ka Flow
ye meri pehli website hai,maine isse GitHub par bnaya hai.
### Browser/client se Server tak ka safar:
1. **Browser(client):**Hum Chrome me website ka naam likhta hain.
2. **HTTP Request:**Browser server ko request bhejta hai.
3. **Server:**Server page dhondhta hai.
4. **Database:**server Database sa lata hai.
5. **Response:**server page wapis Browser ko bhejta hai.
